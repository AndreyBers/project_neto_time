## Краткое резюме

`project_neto_time` - это практический проект по анализу и прогнозированию временных рядов, в котором реализованы подготовка данных, проверка стационарности, стационаризация, сглаживание, ARIMA-моделирование и GARCH-анализ остатков.

Главная ценность проекта - демонстрация полного аналитического процесса и аккуратной работы с временными рядами без нарушения временной структуры данных.

## Описание проекта

`project_neto_time` - аналитический проект по работе с временными рядами. В проекте рассматривается полный цикл подготовки и моделирования временных рядов: загрузка исходных данных, визуальный анализ, проверка стационарности, преобразование рядов, подбор параметров моделей и построение прогнозов.

Основной фокус проекта - классические методы анализа временных рядов:

- проверка стационарности с помощью статистических тестов;
- преобразование нестационарных рядов в стационарные;
- сглаживание временных рядов методами MA / EMA / DEMA / TEMA;
- построение ARIMA-моделей;
- анализ остатков модели;
- построение GARCH-модели для оценки условной волатильности остатков;
- сравнение качества моделей на отложенной выборке.

## Основные ноутбуки

### 1. `stationarize_6_series.ipynb`

Ноутбук для автоматической стационаризации шести временных рядов.

Что делает ноутбук:

- загружает исходные CSV-файлы из `data/raw`;
- приводит каждый датасет к формату временного ряда;
- строит график исходного ряда;
- проверяет стационарность с помощью тестов ADF и KPSS;
- при необходимости применяет преобразования:
  - логарифмирование;
  - разность первого порядка;
  - сезонную разность;
- повторно проверяет стационарность после преобразований;
- сохраняет результат в `data/processed`.

Критерий стационарности:

- `ADF p-value < 0.05`;
- `KPSS p-value > 0.05`.

То есть ряд считается стационарным, если тест ADF отвергает гипотезу о наличии единичного корня, а тест KPSS не отвергает гипотезу о стационарности.

---

### 2. `MA_models_experiment.ipynb`

Ноутбук для экспериментов с моделями сглаживания:

- MA - Moving Average;
- EMA - Exponential Moving Average;
- DEMA - Double Exponential Moving Average;
- TEMA - Triple Exponential Moving Average.

В ноутбуке сравниваются модели на двух типах данных:

1. относительно стационарный дневной ряд;
2. нестационарный месячный ряд с трендом и сезонностью.

Пайплайн эксперимента:

1. Загрузка двух временных рядов.
2. Разделение данных на train и test.
3. Подбор параметров сглаживания на обучающей части.
4. Использование `TimeSeriesSplit` для корректной валидации на временных рядах.
5. Построение прогноза на тестовом периоде.
6. Сравнение моделей по ошибкам прогноза.
7. Визуальная оценка качества прогноза.

Зачем нужен этот ноутбук:

- показать, как простые методы сглаживания работают на разных типах временных рядов;
- сравнить поведение моделей на стационарных и нестационарных данных;
- продемонстрировать базовый подход к подбору параметров для временных рядов.

---

### 3. `arima_experiment_mean_monthly_air_temperature_stationary.ipynb`

Ноутбук посвящен построению ARIMA-модели для стационарного ряда средней месячной температуры воздуха.

Основные шаги:

1. Загрузка подготовленного ряда `mean_monthly_air_temperature_stationary.csv`.
2. Визуализация временного ряда.
3. Построение ACF и PACF.
4. Подбор параметров ARIMA `(p, d, q)`.
5. Выбор лучшей модели по AIC.
6. Обучение модели на train-части.
7. Прогнозирование на test-части.
8. Оценка качества прогноза.
9. Анализ остатков.
10. Дополнительное сравнение с классическими ML-моделями на лагах.

ARIMA используется как базовая статистическая модель для временных рядов, где прогноз строится на основе авторегрессии, интегрирования и скользящего среднего.

---

### 4. `ARIMA_GARCH.ipynb`

Ноутбук расширяет ARIMA-подход за счет моделирования волатильности остатков.

Что реализовано:

1. Загрузка стационарного ряда из CSV.
2. Подбор оптимальных параметров ARIMA по AIC.
3. Обучение ARIMA-модели.
4. Получение остатков модели.
5. Проверка остатков на автокорреляцию.
6. Проверка ARCH-эффекта.
7. Построение GARCH-модели на остатках ARIMA.
8. Анализ качества модели и ее диагностик.

Логика подхода:

- ARIMA описывает среднее значение временного ряда;
- GARCH описывает изменчивость / волатильность остатков;
- комбинация ARIMA + GARCH полезна, если после ARIMA в остатках остается кластеризация дисперсии.

## Используемые методы

### Проверка стационарности

В проекте используются два статистических теста:

#### ADF - Augmented Dickey-Fuller test

Проверяет гипотезу о наличии единичного корня.

- `p-value < 0.05` - ряд можно считать стационарным;
- `p-value >= 0.05` - ряд, вероятно, нестационарный.

#### KPSS - Kwiatkowski-Phillips-Schmidt-Shin test

Проверяет гипотезу о стационарности ряда.

- `p-value > 0.05` - нет оснований отвергать стационарность;
- `p-value <= 0.05` - ряд, вероятно, нестационарный.

Совместное использование ADF и KPSS позволяет надежнее оценить состояние ряда, потому что тесты проверяют разные нулевые гипотезы.

---

### Стационаризация

Для приведения рядов к стационарному виду используются:

1. **Логарифмирование**  
   Применяется для положительных рядов, если у ряда заметен рост масштаба или дисперсии.

2. **Обычное дифференцирование**  
   Используется для удаления тренда.

3. **Сезонное дифференцирование**  
   Используется для удаления сезонной компоненты.

---

### Сглаживание

В проекте используются четыре подхода:

| Метод | Описание |
|---|---|
| MA | простое скользящее среднее |
| EMA | экспоненциальное скользящее среднее |
| DEMA | двойное экспоненциальное сглаживание |
| TEMA | тройное экспоненциальное сглаживание |

Эти методы позволяют оценить базовый прогноз без сложных статистических моделей.

---

### ARIMA

ARIMA-модель задается тремя параметрами:

- `p` - порядок авторегрессии;
- `d` - порядок дифференцирования;
- `q` - порядок скользящего среднего.

В проекте параметры подбираются перебором, а лучшая модель выбирается по критерию AIC.

Чем ниже AIC, тем лучше баланс между качеством описания данных и сложностью модели.

---

### GARCH

GARCH используется для моделирования условной дисперсии остатков.

Модель полезна, если в остатках ARIMA присутствует ARCH-эффект, то есть периоды высокой и низкой волатильности группируются во времени.

В проекте GARCH применяется не к исходному ряду, а к остаткам ARIMA-модели.

---

## Метрики и критерии качества

В проекте используются следующие подходы к оценке:

- визуальное сравнение фактических и прогнозных значений;
- анализ остатков модели;
- AIC / BIC для выбора статистических моделей;
- ошибки прогноза на отложенной выборке;
- проверка автокорреляции остатков;
- тесты на ARCH-эффект.

Для прогнозных моделей могут использоваться следующие метрики:

- MAE - средняя абсолютная ошибка;
- RMSE - корень из средней квадратичной ошибки;
- MAPE - средняя абсолютная процентная ошибка, если она применима к конкретному ряду.

## Особенности работы с временными рядами в проекте

Временные ряды отличаются от обычных табличных данных тем, что порядок наблюдений имеет значение. Поэтому в проекте соблюдаются базовые правила:

- данные не перемешиваются случайным образом;
- обучение происходит на более ранних наблюдениях;
- проверка выполняется на более позднем периоде;
- при кросс-валидации используется временное разбиение;
- прогноз строится только на будущий период относительно train-части.

Такой подход помогает избежать утечки данных из будущего в прошлое.
